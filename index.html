HQ time backups

A personal tool, not a public service.

HQ time tracker is a small time-tracking app that runs on its owner's Raspberry Pi. Every night it encrypts a copy of its own database and uploads it to a folder in its owner's Google Drive, so the data survives if the Pi fails.

It uses Google sign-in only for that upload. It asks for the narrowest Drive permission Google offers (drive.file), so it can see only the folder and files it creates itself, not anything else in the Drive. Nobody else signs in to it.
